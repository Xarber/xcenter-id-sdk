# UADS applicability

The SDK is a library. Section 43 applies to the browser and session boundaries, and sections 4, 10, 18, 42 and 44 apply to integration documentation, supported platforms, the account card, verification and versioning. The registry and manifest record test references and distinguish pending from verified requirements.

The SDK itself has no app shell, on-device release, PWA installation path, independent user account or deployment. The host product owns those concerns. Android and iOS library compilation do not validate a host product's callback, registration or installed behavior.
